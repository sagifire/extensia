# Індекс: domain

## Призначення

Доменна пам'ять Extensia: ubiquitous language, фактичний поточний стан, цільова модель медіаресурсів, інваріанти й відкриті питання.

## Папки

- [Current Domain](current/index.md) - Фактичний стан доменної реалізації після очищення попередньої версії.
- [Target Domain](target/index.md) - Цільова предметна модель релізу `0.1.0` зі статусом draft baseline.

## Файли

- [Glossary](glossary.md) - Словник предметних, runtime та extension-понять Extensia.
- [Rules](rules.md) - Цільові доменні правила та інваріанти предметної моделі.
- [Open Questions](open-questions.md) - Невирішені питання, які не можна неявно перетворювати на contracts.
