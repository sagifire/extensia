## Точний пакет рішень

- Root-only public factory `createExtensia(config)` повертає side-effect-free `ExtensiaModule`.
- Module має states `created|starting|started|stopping|stopped|failed`, normalized `start/stop`, `getState`, nullable dedicated `query/storage` accessors і safe `inspect`.
- Facades видимі тільки після Registry freeze та atomic ready publication; stale facade calls після stop повертають `MODULE_NOT_READY`.
- Result є discriminated union `{ok:true,value}` / `{ok:false,error}`; machine contract використовує `error.code`, не message.
- Phase 2 query catalog: тільки `getResource(rawId)` і one-level `getResourceTree(rawId)`.
- Valid missing ID є `RESOURCE_NOT_FOUND`, invalid raw ID — `INVALID_RESOURCE_ID`; bounded greedy Phase 2 не нормалізує speculative read failure, а unexpected Index/invariant defect лишається exception/diagnostic path.
- Public results повторно використовують canonical UUID v4/Timestamp/deep readonly detached JSON-safe Resource/tree snapshots.
- `ReadonlyResourceDriver` config seam і `storage.createResource(input: unknown): Result<never,...>` позначаються `experimental-phase-2`; command повертає `STORAGE_READONLY` до читання/validation input або будь-якої mutation.
- Facade names не переписуються: canonical lowercase ASCII pattern `^[a-z][a-z0-9]*(?:[.-][a-z0-9]+)*$`, 1..128; `query/storage` reserved для composition-owned system lease `extensia.default-api`, а не self-asserted boolean.
- Registry належить Module lifecycle, provider descriptors збираються synchronous multi contributions, async creation/freeze виконує Extensia Runtime Controller; validation перевіряє trusted channel provenance до reserved ownership.
- Facade calls використовують read-intake leases; `stop()` закриває intake, чекає admitted reads і лише потім dispose-ить runtime. `stop()` після failed не повторює at-most-once startup cleanup і переводить state у stopped.
- Factory capture-ить driver identity у новий frozen config envelope; подальша mutation caller envelope не впливає на module, driver object не clone/freeze-иться.
- Internal shared seam: exact source path `src/system-extensions/default-api/resource-read-port.ts`; exported typed `resource.get` / `resource.tree.get` requests, `CoreReadResult`, overload-based `CoreResourceReadPort` і `CORE_RESOURCE_READ_PORT` token ID `extensia.internal.system-extensions.default-api.core-resource-read-port`; only `RESOURCE_NOT_FOUND` є expected internal error; seam не export-иться з package.
- Semantic owner required-port contract — consumer `extensia.default-api`; окрема BP2-01A materialize-ить єдиний source module до паралельної activation, BP2-02 лише bind/adapt-ить provider implementation.

## Явно не фіксується

- Successful `createResource` input/result semantics та всі інші commands.
- Final Storage Driver methods, concrete storage, atomic protocol, Journal/recovery.
- Plugins, custom facade lookup, hooks, advanced IoC tokens.
- Asset/Mark/KV/global query catalog, lazy completeness або recursive subtree API.
- Final public error catalog, diagnostic compatibility і general release compatibility policy.
- Current implementation claims або production code.
