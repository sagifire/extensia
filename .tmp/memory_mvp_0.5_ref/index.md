# Індекс: memory

## Призначення

Коренева папка Project Memory Starter Kit 5.0 для проекту, у якому використовується PDADM MVP 0.5.

## Папки

- [Reglament](reglament/index.md) - Компактні operational rules PDADM для агентів і Project Memory.
- [Project](project/index.md) - Project-specific адаптації agent і memory rules.
- [Product](product/index.md) - Продуктова пам'ять: бачення, вимоги, roadmap.
- [Domain](domain/index.md) - Доменна пам'ять: поняття, current/target, правила, відкриті питання.
- [Technical](technical/index.md) - Технічна пам'ять: архітектура, стек, правила, ADR.
- [Tasks](tasks/index.md) - Task contracts, runs, research і fixation artifacts.
- [Knowledge](knowledge/index.md) - Reusable knowledge packages та адаптації знань.
- [Templates](templates/index.md) - Шаблони Project Memory і task/run artifacts.
- [Reports](reports/index.md) - Detailed research, audit і periodic reports.

## Файли

- [Agent Start](agent-start.md) - Перша точка входу агента й маршрутизатор читання.
- [Human Start](human-start.md) - Коротка точка входу людини.
- [README](README.md) - Призначення та основні правила використання Project Memory.
- [State](state.md) - Короткий актуальний стан проекту.
- [Inbox](inbox.md) - Сирі ідеї, нотатки й питання до розбору.
