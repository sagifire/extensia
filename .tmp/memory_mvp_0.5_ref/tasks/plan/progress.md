# Прогрес задач

## Без групи

Немає неархівних задач.

## Формат

```markdown
- [ ] **[Backlog]** [TASK-MM.YY-NNNN-short-name](TASK-MM.YY-NNNN-short-name/index.md) - Короткий опис.
- [ ] **[Active]** [TASK-MM.YY-NNNN-short-name](TASK-MM.YY-NNNN-short-name/index.md) - Короткий опис.
- [ ] **[Review]** [TASK-MM.YY-NNNN-short-name](TASK-MM.YY-NNNN-short-name/index.md) - Короткий опис.
- [ ] **[Blocked]** [TASK-MM.YY-NNNN-short-name](TASK-MM.YY-NNNN-short-name/index.md) - Короткий опис.
- [x] **[Done]** [TASK-MM.YY-NNNN-short-name](TASK-MM.YY-NNNN-short-name/index.md) - Короткий опис.
```

Усі неархівні задачі відображаються тут. `canceled` не позначається як виконана робота.

`Type`, current run і artifact details живуть у `task.md`, а не дублюються в `progress.md`.
