# Індекс: memory

## Призначення

Коренева Project Memory Extensia для розробки release `0.1.0` на етапі внутрішнього redesign `v2`. Структура базується на Starter Kit 5.0 і PDADM MVP 0.5.

## Папки

- [Reglament](reglament/index.md) - Компактні operational rules PDADM для агентів і Project Memory.
- [Project](project/index.md) - Project-specific адаптації agent і memory rules.
- [Product](product/index.md) - Продуктова пам'ять: бачення, вимоги, roadmap.
- [Domain](domain/index.md) - Доменна пам'ять: поняття, поточна і цільова модель, правила, відкриті питання.
- [Technical](technical/index.md) - Технічна пам'ять: архітектура, стек, технічні правила, ADR.
- [References](references/index.md) - Project-specific detailed source specifications, на яких базується canonical memory.
- [Tasks](tasks/index.md) - Task contracts, universal runs, research і fixation artifacts.
- [Knowledge](knowledge/index.md) - Reusable knowledge packages та адаптації знань.
- [Templates](templates/index.md) - Шаблони задач, прогонів, research reports, audit reports, ADR і knowledge packages.
- [Reports](reports/index.md) - Періодичні огляди, research reports і audit reports.

## Файли

- [Agent Start](agent-start.md) - Перша точка входу агента в Project Memory.
- [Human Start](human-start.md) - Коротка точка входу для людини, яка ще не знає регламент.
- [README](README.md) - Вхідна точка Project Memory для людини й агента.
- [State](state.md) - Короткий актуальний стан проекту.
- [Inbox](inbox.md) - Місце для сирих ідей, нотаток і питань.
