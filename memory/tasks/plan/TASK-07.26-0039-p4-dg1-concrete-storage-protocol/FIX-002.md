# FIX-002: Зафіксувати taxonomy storage driver families

## Мета

Зафіксувати architecture framing і taxonomy, у якій SQLite є first `embedded-transactional` profile, а filesystem і PostgreSQL/MySQL розвиваються окремими physical families того самого semantic port.

## Exact proposed changes

### `memory/technical/architecture.md`

Додати section `Storage Driver families`:

- Extensia не є database engine; Storage Driver реалізує Core-owned semantic persistence port.
- Canonical families: `filesystem-native`, `embedded-transactional`, `client-server-transactional`.
- `local-sqlite-v1` — first/default `embedded-transactional` profile release `0.1.0`, але не universal physical model.
- Shared authority: session/coherence, atomic semantic commit, one committed journal, idempotency, recovery-before-ready, readonly, integrity і outcome truth.
- Profile-local authority: files/sidecars/native calls, SQL/schema/isolation, server topology, lock і physical recovery.
- Core/public API не бачать family-specific physical details.

### `memory/technical/rules.md`

Додати invariants:

- новий driver profile декларує family, exact capability/support boundary і executable conformance matrix;
- semantic contract не стандартизує physical layout/SQL/lock mechanism між families;
- filesystem sidecar records не вважаються lock/directory durability primitive без verified native/platform guarantee;
- client-server profiles reconcile-ять network-ambiguous COMMIT за durable `operation_id` і не маскують unknown як reject;
- vendor profiles не зводяться до lowest-common-denominator, якщо це послаблює semantic guarantees.

### `memory/technical/open-questions.md`

Закрити питання family taxonomy. Додати окремі open design gates для filesystem-native exact native/sidecar protocol і PostgreSQL/MySQL vendor profiles. Лишити implementation certification `local-sqlite-v1` відкритою до P4-WP1.

### `memory/product/roadmap.md`

У Phase 4 вказати `local-sqlite-v1` як first/default embedded profile після application gate. У post-0.1 roadmap додати filesystem-native і client-server transactional official driver research без release `0.1.0` implementation claim.

### `memory/state.md` і `memory/domain/current/implementation-state.md`

Після application відобразити taxonomy як accepted target design, а всі concrete production drivers — not implemented. Не описувати PostgreSQL/MySQL/filesystem profile як supported capability.

### Indexes

Оновити безпосередньо пов'язані wiki indexes лише якщо створюються нові canonical documents; цей proposal за замовчуванням доповнює existing documents і не створює нового ADR понад FIX-001/ADR-0010.
