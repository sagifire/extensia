## Призначення

Усунути ambiguity між accepted requirements/technical rules і `proposed` status ADR-0004/ADR-0005, не стабілізуючи conceptual signatures.

## Підсумок джерела

Accepted requirements уже вимагають facade-first boundary, frozen Registry, Core-driven writes, Storage Driver source of truth, committed journal publication, post-commit index і recovery. ADR-0004/0005 описують саме цю суть, але досі мають `proposed` status.

## Цільові файли пам'яті

- `memory/technical/decisions/ADR-0004-facade-first-extension-boundary.md`
- `memory/technical/decisions/ADR-0005-core-operation-consistency.md`
- `memory/technical/decisions/index.md`

## Запропоновані зміни

- Змінити status ADR-0004 і ADR-0005 з `proposed` на `accepted` за умови explicit approval цього fixation.
- Додати clarification: accepted є architecture semantics/boundary; exact facade methods, result/error DTO, hook names, storage protocol, journal format і recovery matrix лишаються planned design gates.
- Оновити descriptions у decisions index з `Запропонована` на `Прийнята`.

## Обґрунтування

Authority status має відповідати accepted requirements. Збереження exact signatures як draft уникає неправильного freeze і не зменшує роль P2/P3/P4/P6 design gates.
