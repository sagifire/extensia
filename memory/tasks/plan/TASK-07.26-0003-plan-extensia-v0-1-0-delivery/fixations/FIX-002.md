## Призначення

Зафіксувати перевірений contract `@sagifire/ioc@0.0.2` та date-bound Phase 1 TypeScript/build/test/package baseline.

## Підсумок джерела

Exact package tarball підтвердив typed tokens, modules, graph validation, adapters, cardinality, scopes, inspection і disposal. Він не має async multi contributions і не визначає Extensia lifecycle. Tooling research обрав unbundled `tsc`, TypeScript 6.0.3, Vitest 4 і explicit package gates; TypeScript 7 не обрано через актуальний peer range lint stack.

## Запропоновані зміни

- У stack зафіксувати exact runtime dependency `@sagifire/ioc@0.0.2`, обрані tooling versions, `tsc` ESM-only build, NodeNext/ES2024, Vitest/V8, npm lockfile, explicit exports і package checks.
- Зафіксувати, що BP1-01 прибирає `package-lock.json` з `.gitignore` і commit-ить lockfile; сама planning fixation project files не змінює.
- Позначити version snapshot як date-bound; upgrades мають бути окремими tasks.
- Зафіксувати package layout/public-internal-testkit rules: root-only Phase 1 export; `./testkit`, `./driver`, `./plugin` лише після contract gates; no wildcard internal exports.
- У open questions закрити exact IoC/tooling question посиланням на ADR-0006; лишити public config, token policy, registry ownership і testkit public status відкритими до owner stages.
- В ADR-0006 описати actual IoC limitations: synchronous multi contributions, Extensia-owned lifecycle/extension graph, fresh-composition test policy.

## Обґрунтування

Phase 1 не може бути reproducible без exact package/toolchain baseline. ADR захищає від буквального копіювання conceptual sketches, які очікують capabilities, відсутні у package.
