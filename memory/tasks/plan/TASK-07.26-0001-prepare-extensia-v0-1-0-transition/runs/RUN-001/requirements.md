# RUN-001: вимоги

## Мета прогону

Підготувати репозиторій до старту розробки `extensia v0.1.0` як умовної v2 без успадкованого коду, тестів, збіркової інфраструктури й старої Project Memory попередньої версії.

## Вимоги

- Видалити код попередньої версії, включно з тестами.
- Видалити або скинути збіркову інфраструктуру попередньої версії до нейтрального стартового стану.
- Видалити стару пам'ять проекту в папці `rmem`.
- Перевести релевантні конфігурації на Node.js 24.
- Скинути `package.json` до мінімуму, потрібного для старту нової версії.
- Видалити `package-lock.json`.
- Видалити `node_modules`.
- Перевірити, що не залишилось активних посилань на старий код, тести, збірку, залежності або `rmem`.

## Поза межами прогону

- Не реалізовувати функціональність `extensia v0.1.0`.
- Не проектувати нову архітектуру v2, якщо для цього потрібна окрема design або architecture task.
- Не мігрувати дані зі старої папки `rmem`.
- Не зберігати зворотну сумісність зі старою версією.
- Не публікувати пакет і не готувати реліз.

## Критерії завершення

- Репозиторій очищений від старого коду, тестів і старої збіркової інфраструктури.
- `rmem`, `package-lock.json` і `node_modules` відсутні.
- `package.json` містить мінімальні метадані, Node.js 24 engine і тільки релевантні скрипти без старих залежностей.
- Виконана перевірка залишкових посилань.
- `result.md` містить перелік змін, перевірок, ризиків, memory sync і self-review.
