# RUN-001: контекст

## Вихідний контекст

Задача є destructive cleanup перед новим етапом розробки. Видалення старого коду, тестів, `rmem`, lockfile і `node_modules` входить в явний scope задачі.

## Робочі правила

- Перед видаленням директорій перевірити, що цільові шляхи знаходяться всередині workspace.
- Не змінювати нову Project Memory у `memory/`, крім task artifacts, task status і потрібних індексів.
- Не створювати нову архітектуру або API в цьому прогоні.
- Не переносити task folder між статусними директоріями; статус змінювати тільки в `task.md` і `tasks/plan/progress.md`.

## Очікувані перевірки

- Огляд кореневих файлів і директорій до очищення.
- Пошук залишкових посилань на стару пам'ять `rmem`.
- Пошук залишкових посилань на старі тести, build scripts і dependency names після очищення.
- Перевірка фінального git diff.
