## Exact invariants

- `commit(entryDraft)` фіксує ordered staged Resource write-set і рівно один committed journal entry; resolve = committed, reject = not committed. Idempotency використовує canonical SHA-256 fingerprint повного ordered staged write-set.
- `JournalSequence` — positive decimal string від `1`, contiguous/gap-free, призначена driver під exclusive storage session; Timestamp не визначає order. Unknown/ahead/missing cursor є integrity failure.
- Persistent journal містить лише committed entries; started/failed/rolled-back — runtime diagnostics або driver-private staging.
- Core reload-ить current committed state й готує immutable validated index delta під storage session до commit; після resolve виконує synchronous no-fail publication swap.
- Full startup утримує одну recovery-clean exclusive session через recovery, committed scan, index build і journal-head capture до ready.
- Create підтримує лише generated root Resource з exact own `title` і optional `description`; update — лише effective own `title`/`description` patch.
- Committed post-commit fault повертає committed success із bounded warning та fail-close/unpublication; він не перетворюється на failure/throw.
- ID collision має максимум три candidates/attempts із release session -> release local lock -> regenerate/replan; третя collision дає `RESOURCE_ID_GENERATION_FAILED`.
- Full driver у config є frozen opaque handle від `defineFullResourceDriver`; callable session/transaction існують лише в experimental driver-author definition boundary.
- Readonly capability failure виконується до inspection input. Full driver/create/update labels — `experimental-phase-3`; `defineFullResourceDriver` — `experimental-driver-author`.
- Operation ID і actor ID є internal UUID v4. Повторний operation ID є idempotent лише для identical full draft/write-set fingerprint; mismatch є integrity failure. Public idempotency/deduplication у P3 не обіцяється.
- Canonical contract відтворює exact detached readonly public create/update input/result/error/warning union, повний error-code snapshot і discriminated readonly/full driver-config shape з opaque full-driver handle; broad `unknown` input лишається лише descriptor-safe facade boundary.
