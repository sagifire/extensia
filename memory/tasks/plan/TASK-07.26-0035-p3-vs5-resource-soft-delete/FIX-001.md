## Target files

## Exact proposed changes

1. У `memory/domain/current/implementation-state.md` у підсумку current implementation додати experimental leaf-only Resource soft delete, dense sibling reindex і default tombstone invisibility; прибрати delete зі списку відсутніх можливостей. Зафіксувати, що command success повертає detached tombstone, тоді як default get/tree та update/move/Marks/KV не розкривають tombstone.
2. У `memory/technical/architecture.md` після абзацу P3-VS4 додати, що P3-VS5 розширила той самий Core/Operation Engine pipeline operation kind `resource.delete`: coarse hierarchy lock, coherent leaf eligibility, exact sorted target+sibling prepared set зі спільною timestamp, one semantic commit/journal entry/fingerprint, batch index publication і detached tombstone result. Зафіксувати default invisibility та startup active-parent/dense-order integrity reuse; restore/include-deleted/cascade/purge/retention лишити deferred.

## Rationale

Після позитивного human review canonical current/technical memory має відображати фактично прийняту реалізацію без змішування з target state.
